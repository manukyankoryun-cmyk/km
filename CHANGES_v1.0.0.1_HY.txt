KM — Իրավական անկյուն և արձագանքման բարելավումներ
Թարմացում՝ v1.0.0.1, 02.10.2026

Սա ամբողջական փոփոխված նախագծի արխիվն է։ Նոր Windows Setup.exe այս միջավայրում չի հավաքվել։

ԿԱՏԱՐՎԱԾ Է
1. Իրավական ընթերցիչն այլևս յուրաքանչյուր 9000 նիշից մեխանիկորեն չի կտրում տեքստը։ Էջերի սահմանները հաշվի են առնում պարբերությունները և վերնագրերը։ Բացառիկ երկար պարբերությունները բաժանվում են բառերի սահմաններով, եթե հնարավոր է։
2. Վերականգնվել է մաս / բաժին / ենթաբաժին / գլուխ / հոդված տարբերակումը։ Առանձին պարբերությամբ գրված վերնագրերը միացվում են դրանց համարներին ընթերցիչում և բովանդակության ցանկում։
3. Ցուցադրման համար վերծանվում են մնացած HTML նշանները, այդ թվում՝ &#9878։ Սկզբնական իրավական կատալոգը պահպանված է անփոփոխ։ Իրավական բովանդակությունը նորից չի գրվել կամ թարմացվել։
4. 33,147,131 բայթ ընդհանուր կատալոգի փոխարեն ընթերցիչը բեռնում է 632,437 բայթ ցանկ, ապա միայն ընտրված փաստաթուղթը։ 1262 տեքստի էջերի և բովանդակության տվյալները պատրաստվում են նախապես։
5. Հրամանից «Վերադարձ»-ը բացում է նույն ենթաբաժնի հրամանների ցանկը։ Կառավարության որոշումների և հրահանգների ցանկերից վերադարձը բացում է իրավական գլխավոր բաժինը։
6. Արագ էջափոխման ժամանակ ուշացած հարցումն այլևս չի վերագրում նոր բացված էջը։ Որոնումը սպասում է մուտքագրման կարճ դադարին։
7. Ընթերցիչի պարբերությունները, վերնագրերը, որոնումը և կառավարման կոճակները հարմարեցված են նեղ պատուհանին։ Իրավական տեքստն առանձնացված է միջերեսի ավտոմատ թարգմանությունից։
8. Բնութագիր / խրախուսանքներ / կարգապահական տույժեր կոճակները անհրաժեշտության դեպքում նախ բեռնում են իրենց մոդուլները։ Օրենսգրքերի գլխավոր էջից հանվել է հին ֆայլային վահանակի կրկնվող հատվածը։
9. Ընդհանուր տառաչափը կիրառվում է CSS-ով՝ էջի յուրաքանչյուր տարրի պարբերական շրջանցման փոխարեն։ Ֆոնային մոդուլների բեռնման միջև ավելացվել են առանձին սպասումներ։ Ընտրացանկը բացելիս այլևս չի արտահանվում էջի ամբողջ HTML-ը՝ դատարկությունը ստուգելու համար։
10. Թարմացման համարը և հավաքման տարբերակի ստուգումը համապատասխանեցվել են 1-ին։ Ֆայլերի ամբողջականության տվյալները վերահաշվարկվել են նախագծի ստանդարտ writeIntegrity գործառույթով՝ Electron 22.3.27-ով։ Պաշտպանության ստուգումները չեն անջատվել։

ՍՏՈՒԳՎԱԾ Է
- Տվյալների ստուգում՝ 1262 փաստաթուղթ, 2948 էջ, 9714 վերնագիր։ Էջերը հերթականությամբ միացնելիս ամբողջ ցուցադրվող տեքստը պահպանվում է։
- index.html-ի 27 ներկառուցված JavaScript հատվածները շարահյուսորեն վավեր են։
- Chromium-ում ընթերցիչի որոնում, հաջորդ գտածո, առաջին/նախորդ/հաջորդ/վերջին էջ, բովանդակությունից հոդվածի ընտրություն։
- 18 սահմանադրություն/օրենսգիրք, 4 կանոնագրքի պահված նյութ, կրթական իրավունքների նյութ, հրամանների 6 ենթաբաժին, կառավարության որոշումներ, հրահանգներ և իրավունքների գլխավոր էջ։
- Հրամանի ցանկ վերադարձ, արագ էջափոխման ընթացքում ուշացած հարցման կանխում։
- 1280×900 և 600×850 պատուհաններ։ 600 պիքսել լայնությամբ ընթերցիչում հորիզոնական արտահոսք չկա։
- Այս UI փորձարկումները կատարվել են ծրագրի իրական ոճերով և ընթերցիչի կոդով՝ առանձին փորձարկման էջում, ոչ Windows-ի ամբողջ հավելվածում։ JavaScript սխալներ չեն գրանցվել։

ՉՍՏՈՒԳՎԱԾ / ՍԱՀՄԱՆԱՓԱԿՈՒՄՆԵՐ
- Windows Setup-ի հավաքում և Windows-ում ամբողջ ծրագրի գործարկում այս Linux միջավայրում չեն կատարվել։
- Նախագծի guard regression ստուգումներից 33-ն անցել են, 4-ը կանգնել են ներկառուցված ai_clone պաշտպանության պատճառով՝ փորձարկման միջավայրում։ Այդ պաշտպանությունը չի շրջանցվել։
- Օգտատիրոջ համակարգչի մեկնարկային, accounting, people և positions ուշացումների վերացումը չի հաստատվել։ Վերոնշյալ փոփոխությունները նվազեցնում են կոնկրետ ավելորդ աշխատանքը, բայց նոր freeze report է անհրաժեշտ։
- Բացակայող պաշտոնական իրավական տեքստեր չեն հորինվել։ Մասնակի և ներքին նյութերի առկա զգուշացումները պահպանված են։

WINDOWS-ՈՒՄ ՀԱՎԱՔՈՒՄ
1. Բացեք արխիվի 0011 պանակը՝ առանձին աշխատանքային պանակում։
2. Գործարկեք BUILD_SETUP.cmd։ Այն օգտագործում է նախագծի առկա Electron/NSIS պատրաստման ընթացակարգը։ Եթե գործիքները բացակայում են, սկզբնական նախագծի հավաքման ընթացակարգը կարող է պահանջել համացանց։
3. Հաջող հավաքումից հետո ստուգեք dist\KM_Setup_x64.exe-ը և գործարկեք VERIFY_FINAL_SETUP.cmd։
4. Windows-ում ստուգեք իրավական ենթաբաժինները և կրկնեք freeze report-ի նույն քայլերը՝ մեկնարկ, ընտրացանկ, accounting, people, positions և lawdocs։
