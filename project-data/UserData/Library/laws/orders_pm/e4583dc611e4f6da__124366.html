3 օգոստոսի 2018 թվականի N 1048-Ա

 

«ՍԱՀՄԱՆՎԱԾ ԿԱՐԳԻ ԽԱԽՏՄԱՄԲ ՊԱՐՏԱԴԻՐ ԶԻՆՎՈՐԱԿԱՆ ԾԱՌԱՅՈՒԹՅՈՒՆ ՉԱՆՑԱԾ ՔԱՂԱՔԱՑԻՆԵՐԻ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔՈՒՄ ՓՈՓՈԽՈՒԹՅՈՒՆ ԿԱՏԱՐԵԼՈՒ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔԻ ԿԻՐԱՐԿՈՒՄՆ ԱՊԱՀՈՎՈՂ ՄԻՋՈՑԱՌՈՒՄԸ ՀԱՍՏԱՏԵԼՈՒ ՄԱՍԻՆ

 

Հայաստանի Հանրապետության կառավարության 2004 թվականի ապրիլի 8-ի N 541-Ն որոշման 1-ին կետին համապատասխան`

Հաստատել «Սահմանված կարգի խախտմամբ պարտադիր զինվորական ծառայություն չանցած քաղաքացիների մասին» Հայաստանի Հանրապետության օրենքում փոփոխություն կատարելու մասին» Հայաստանի Հանրապետության 2018 թվականի հունիսի 19-ի ՀՕ-346-Ն օրենքի կիրարկումն ապահովող միջոցառումը` համաձայն հավելվածի:
