┌─ app\                          ← Electron/KM desktop runtime (ծրագրի կոդ)
│   ├─ js\                       ← UI, Help Bot, գրաֆիկ, library
│   ├─ data\                     ← JSON կոնֆիգ, bulk-import JSONL
│   │   └─ bulk-import\          ← 700k curriculum import (npm run bot:import)
│   ├─ scripts\                  ← bot:reindex, FTS, LAN setup
│   ├─ docs\                     ← LAN_SETUP.md և այլն
│   ├─ assets\                   ← icon, background images
│   ├─ main.js, preload.js, index.html
│   └─ package.json
│
├─ scripts\                      ← Build, test, icon, KOD (root-level dev scripts)
├─ tools\                        ← PDF/font build helpers
├─ dist\                         ← KM_Setup_x64.exe output
├─ setup\                        ← NSIS header/welcome bitmaps
├─ _cache\                       ← build cache (rcedit, png-to-ico)
│
├─ BUILD_SETUP.cmd               ← x64 installer build
├─ VERIFY_FINAL_SETUP.cmd
├─ KM_Setup_x64.nsi
│
└─ project-data\                 ← Dev mirror / backup (ստեղծվում է script-ով)
    ├─ UserData\                 ← %LOCALAPPDATA%\KM\UserData-ի պատճեն
    │   └─ BotKnowledge\
    │       ├─ qa.jsonl
    │       ├─ knowledge.db
    │       └─ vectors\
    └─ README.txt
